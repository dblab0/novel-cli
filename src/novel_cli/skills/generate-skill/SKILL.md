# 技能设定生成

## 输出模板

生成技能/功法设定时，严格按照以下格式输出到 Markdown 文件。

文件名：`{entity_id}.md`
输出路径：`skills/{entity_id}.md`

````markdown
# <技能名>

## 基本信息
- 名称：
- 类型：（功法/法术/武技/神通/秘术）
- 等级/品阶：
- 来源/创立者：

## 描述
<功法本质、核心原理概述>

## 修炼条件
- 境界要求：
- 特殊要求：

## 效果
- <核心能力与效果>

## 传承脉络
<简洁链式描述：A(创立) → B(获得) → C(修炼)>
````

## 字段规则

- **必填**：名称、类型、等级、描述
- **等级/品阶**：按世界观体系（如天地玄黄、品阶等）
- **修炼条件**：包含境界要求和特殊要求（如灵根属性）
- **效果**：列出功法/技能的核心能力和效果
- **传承脉络**：简洁链式文本，如 `千竹教祖师(创立) → 金南天(抢得) → 林师兄(修炼至第三层) → 韩立(获得玉简)`，不按章节追踪细节
- **无信息字段**：标注"无相关描述"，不编造内容
