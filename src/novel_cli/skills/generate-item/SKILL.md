# 物品设定生成

## 输出模板

生成物品设定时，严格按照以下格式输出到 Markdown 文件。

文件名：`{entity_id}.md`
输出路径：`items/{entity_id}.md`

````markdown
# <物品名>

## 基本信息
- 名称：
- 类型：（武器/法宝/丹药/材料/令牌/其他）
- 等级/品阶：
- 来源：

## 外观
- 形状：
- 颜色：
- 纹路：
- 触感：

## 功能
- **<功能名>**：<功能描述>

## 使用条件
- <使用限制/要求>

## 来历
<物品的起源故事，无则省略>
````

## 字段规则

- **必填**：名称、类型、描述、功能
- **等级/品阶**：根据世界观体系填写（如天地玄黄、品阶等）
- **外观**：从原文中提取具体描述，尽量生动
- **来历**：有起源故事时填写，无则可省略整节
- **无信息字段**：标注"无相关描述"，不编造内容

## 信息收集策略

```
Step 3: SearchGraph(entity_id, rel_type="创造,持有")
Step 4: SearchCorpus(物品别名, chapter_ids)        → 正名+别名
        SearchCorpus(材质/重量关键词, chapter_ids)  → 属性参数
        SearchCorpus(功能关键词, chapter_ids)       → 功能描述
        以上并行调用
Step 5: 必要时 ReadChapter 获取关键段落原文
```
