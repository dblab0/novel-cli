# 地点设定生成

## 输出模板

生成地点设定时，严格按照以下格式输出到 Markdown 文件。

文件名：`{entity_id}.md`
输出路径：`locations/{entity_id}.md`

````markdown
# <地点名>

## 基本信息
- 名称：
- 类型：（宗门/城市/山脉/洞穴/秘境/村庄/其他）
- 位置：
- 势力归属：

## 描述
<地点概况描述>

## 特色
- <特色要点，3-5条>

## 环境要点
- 视觉元素：
- 关键地点：

## 关联设定
### 常驻人物
| 人物 | 身份 |
|------|------|

### 所属组织
<如有>
````

## 字段规则

- **必填**：名称、类型、描述
- **势力归属**：无归属填"无"
- **特色**：从原文中提取该地点的独特之处
- **环境要点**：用于写作时的视觉参考，尽量具体生动
- **常驻人物**：列出在该地点活跃的角色及身份
- **无信息字段**：标注"无相关描述"，不编造内容
