读取小说章节全文或指定句子范围。

**定位**：兜底/补全工具。搜索空结果时读整章，或搜索结果间有信息空白时按范围补全。

| 参数 | 必填 | 说明 |
|------|------|------|
| `chapter_id` | 是 | 章节 ID |
| `start` | 否 | 起始句子索引（含）。不传则从开头读取 |
| `end` | 否 | 结束句子索引（不含）。不传则读取到章节末尾 |

**使用示例**：
```
ReadChapter(chapter_id=173)                                    → 读取整章
ReadChapter(chapter_id=173, start=10, end=20)                  → 读取指定范围
```

**何时使用**：
1. SearchCorpus 搜索空结果 → 用 `chapter_id` 读整章
2. 搜索结果间有信息空白 → 用 `start` 和 `end` 补全

**Token 成本控制**：
- 整章读取成本较高，已知大致位置时优先使用 `start` 和 `end`。
- 返回整章时会附带总句子数，方便后续精确取值。
