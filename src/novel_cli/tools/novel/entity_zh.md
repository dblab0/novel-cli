在小说知识库中搜索实体（人物、法宝、宗门、地点等）。
返回匹配的实体名称、类型、描述，以及用于 SearchGraph 和 SearchCorpus 的 `entity_id`。

**选择 `search_mode`**：

| 模式 | 使用场景 | 查询要求 |
|------|----------|----------|
| `name` | 已知实体的确切名称 | 单个名称（如"韩立"、"青竹蜂云剑"） |
| `vector` | 仅知道特征或描述 | 单个核心关键词（如"隐匿术"） |

**关键规则 — 每次查询只用一个关键词**：
无论使用哪种 search_mode，每次调用都应只使用**一个**核心词。
多个关键词会稀释两种模式的搜索信号。

正确示例：
- SearchEntity(query="韩立", search_mode="name")
- 需要查询多个实体 → 并行调用，每次一个名称

错误示例：
- SearchEntity(query="韩立 师傅 功法")  ← name 模式下包含多个名称
- SearchEntity(query="虚天殿 冰焰")     ← vector 模式下包含两个概念

**失败恢复**（必须严格遵循，不要重复使用 name 模式）：
1. name 模式无结果 → **必须**立即切换到 vector 模式，使用相同关键词
2. 将查询缩减为单个核心关键词
3. 回退到 SearchCorpus，使用 `keywords` 进行直接文本搜索
